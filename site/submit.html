Submit your solution

Before the deadline, make your repository public and open one pull request that adds your submission.json.

Deadline: Saturday, November 14, 2026 at 4:00 pm Central Time (Fargo, ND). Pull requests opened or changed after the deadline are not accepted.
Don’t open your pull request early. Submissions are public, and the rules prohibit sharing solutions. Build privately, then submit shortly before the deadline.

Steps

  1. Make your solution repository public. In your repository: Settings → General → Danger Zone → Change visibility. Its README must reproduce your results.
  2. Fork Bluestaq/ndsu-hackathon-submissions.
  3. Add exactly one file in your fork: submissions/<your-github-username>/submission.json.
  4. Open a pull request to main and complete the checklist.
  5. Watch the Submission check. If it fails, read the job summary, fix the file, and push again to the same branch before the deadline.

With Git

git clone https://github.com/<your-github-username>/ndsu-hackathon-submissions.git
cd ndsu-hackathon-submissions
git switch -c submission
mkdir -p submissions/<your-github-username>
cp /path/to/submission.json submissions/<your-github-username>/submission.json
python starter/submission/validate_submission.py submissions/<your-github-username>/submission.json
git add submissions/<your-github-username>/submission.json
git commit -m "Straight Rows submission: <your-github-username>"
git push -u origin submission

Then open the pull request from the link Git prints, or from your fork’s page on GitHub.

In the browser

In your fork, choose Add file → Create new file. Type submissions/<your-github-username>/submission.json as the name, paste your JSON, choose Create a new branch, and propose the change.

What the check verifies

One file, your folder

Only submissions/<you>/submission.json changes.

It’s you

github_handle matches your account, and repository_url is a public repository you own.

Well-formed

Identifiers, timestamps, confidence and evidence pass the starter validator.

Private details stay private

No email address or student ID.

On time

Opened and last changed before 4:00 pm Central on Saturday, November 14.

The check never runs your code and never scores you. Scoring runs once, after the lock, and the results page is updated after review. Judges choose the winner with the 100-point rubric; the automated diagnostic is supporting evidence.
