Setup · About 15 minutes

Get started

Clone the starter, download the data at kickoff, run the baseline, and build in your own private repository.

1. Before the event

  1. Create a free GitHub account if you don’t have one. Your GitHub username is how you are identified on submissions and results.
  2. Install Git and Python 3.11 or newer.
  3. Create a private repository for your solution, for example straight-rows. You will make it public when you submit.

2. Clone the starter

git clone https://github.com/Bluestaq/ndsu-hackathon-submissions.git
cd ndsu-hackathon-submissions
python -m venv .venv
source .venv/bin/activate          # Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r starter/requirements.txt

Copy the starter/ folder into your own private repository and work there.

3. Download the data (at kickoff)

python starter/scripts/get_data.py

This downloads the official dataset from the latest release, verifies its checksum, and extracts it into starter/data/. Until kickoff it reports that the dataset has not been released yet. You can also download StraightRows_Student_Package.zip from the release page and run python starter/scripts/get_data.py --zip PATH.

Farm telemetry

72 simulated hours × 3 tractors × 1 Hz: position, speed, cross-track error, satellites, C/N0, fix state, correction link.

Space context

Kp, Dst, regional S4 scintillation, constellation advisories, and delayed, imperfect interference reports.

Labels

12 labeled development episodes (hours 0–48). Eight unlabeled evaluation episodes (hours 48–72) are scored.

4. Your first working result

cd starter
python submission/baseline.py --data data --output submission.json \
  --github-handle YOUR_GITHUB_USERNAME \
  --repo-url https://github.com/YOUR_GITHUB_USERNAME/YOUR_SOLUTION_REPO
python submission/validate_submission.py submission.json

For the optional notebook: python -m pip install jupyterlab, then jupyter lab notebooks/starter_notebook.ipynb.

Submissions are public. Identify yourself only by GitHub username. Never put your email address or student ID in submission.json; the validator rejects them.

5. Improve it

Inspect a labeled episode, ask whether the explanation and evidence are useful, then make one change you can measure. The official guide lists the causes, actions, data, and the judging rubric. Any language, internet resources, and AI coding assistants are allowed; you must be able to explain and defend your work.
